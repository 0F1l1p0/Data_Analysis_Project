# Data_Analysis_Project
Creating scripts for comprehensive data analysis 

A data analytics project that contains a collection of scripts for various types of analyses, including:

- Changes over time  
- Cumulative analysis  
- Performance analysis  
- Proportional analysis  
- Data segmentation  
- Various types of reporting  

IMPORTANT PREREQUISITE: This Project depends on the Data_Warehouse_Project. 
Before running this analysis, you need to set up and run the data warehouse : https://github.com/0F1l1p0/Data_Warehouse_Project

Run the SQL scripts in your preferred SQL environment (e.g., SQL Server Management Studio) after the data warehouse has been set up.
The project focuses on deriving insights such as trends, customer behavior, and product performance.
